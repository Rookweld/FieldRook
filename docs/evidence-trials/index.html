02 / METHODOLOGY

Proof requires
boundaries.

This is an auditable demonstration of specific code paths. It is not a claim that FieldRook can solve any Windows problem or that a language model is always correct.

01

Synthetic by design

Every displayed measurement comes from deterministic FieldRook fixtures, not someone else's workstation. Inference is explicitly simulated.

02

Evidence before inference

Facts and hypotheses cite exported evidence IDs. The UI lets you inspect the underlying bounded tool readings and known gaps.

03

Claims are not fixes

Recovery cases record a manual intervention claim. Fresh re-measurement determines VERIFIED_RESOLVED or NOT_RESOLVED. No automated recovery runs here.

04

Reproduce the test

Check out the referenced commit, run the offline gauntlet, and use the published export script to regenerate the evidence. No cloud API key needed.

REPRODUCTIONcd backend && python -m eval.run
